# RaatPharmacy — Design

World (pinned by the brief, seed: none (pinned)): premium night pharmacy.
Deep emerald ink (`#061f1c`) with a warm mint accent (`#34e5a6`), amber for
closing-soon, soft layered shadows, Sora for Latin display + Hind Siliguri
for Bangla. Dark is the use scene (night); a light theme follows the
system setting, the header stays dark in both.

Mode: Operate with Persuade-level polish in the header/hero. The job is
"find an open pharmacy tonight, fast": search first, stats as filter
chips (All / Open now / Past midnight), sticky filters on phones, a
300px sidebar + 2-column grid on desktop.

Rules kept: no emoji icons (inline SVG only), no gradient text, no
kicker/eyebrow, no one-sided border bar on cards, touch targets ≥44px,
header stacks on phones (the clock pill never covers the brand),
reduced-motion respected, focus rings + themed selection/scrollbars.

Data: `data/pharmacies.json` — 94 verified pharmacies (41 original + 53 added 26 Nov 2026), never edited here.
